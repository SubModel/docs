# preview-20260803

**Release date:** August 3, 2026

This release ships the `preview-20260803` API tag across the full Submodel platform, introducing the Discovery recommendation engine, a rewritten SDK layer, comprehensive documentation, and an automated test suite that brings coverage to 148 unit tests.

---

## Highlights

- **Discovery API** — stateless, explainable GPU plan recommendation engine (≤3 candidates, deterministic ranking, no LLM inside the decision path).
- **SDK rewrite** — `ServerlessWorker` replaces the old `ServerlessHandler`; exception codes 40100 and 40400 now map to typed exceptions; URL paths corrected for `_requests` endpoint.
- **Auto Recharge UI** — new billing page lets users configure threshold + top-up amount; saved payment method management.
- **Log Viewer overhaul** — XSS-safe `v-html` path (HTML-escape before highlight inject), WebSocket real-time streaming with batch processing and reconnect backoff.
- **Test automation** — 148 Python SDK tests, 3 Vue unit test suites, 2 backend pure-function test suites. QA no longer needs a running stack for SDK or unit-level checks.

---

## What's New

### Discovery API (`backend-source`)
- `POST /api/v1/discovery/recommend` — returns ranked GPU plan candidates based on user-supplied intent (mode, gpu_count, gpu_mem_min, area, billing, sort_priority, max_price). Hard-filtered against the authenticated user's visible plans only; caps at 3 candidates.
- `POST /api/v1/discovery/event` — privacy-safe append-only lifecycle event log; allowlisted fields only (EL-REQ-001/002).
- `GET /api/v1/discovery/metrics` — admin-only aggregated metrics with minimum cohort rule (EL-REQ-004/006).
- Feature flags default **OFF** (`DISCOVERY_ENABLED`, `DISCOVERY_EVENT_WRITE`, `DISCOVERY_BASELINE`) — shadow exploration only until trust-gate passes (EL-REQ-005).

### Python SDK (`submodel-sdk-python`)
- `ServerlessWorker` is now the canonical class name (was `ServerlessHandler`).
- `exceptions.py` — added code 40100 → `AuthenticationError`; code 40400 → `ResourceNotFoundError`.
- `endpoint.py` — corrected `get_requests()` and `get_request_details()` to use `/_requests` path.
- Full test suite: 148 tests across 6 modules, all green.

### Frontend (`webapp-source`)
- **AutoRecharge.vue** — new account page: enable/disable auto-recharge, select threshold (cents) and top-up amount (USD), add/remove saved payment method.
- **LogViewer.vue** — XSS fix: `highlightSearchTerm()` now HTML-escapes content before regex replace + v-html injection. WebSocket auth token sent in message body (not URL). Batch processing for high-throughput log streams.
- **DeploymentAssistant.vue** — recommendation panel integrated with Discovery API.

### Documentation
- New SDK section in EN + ZH docs: CLI reference, Pod API, Serverless API, Storage API.
- Billing Information pages updated with Auto Recharge section (EN + ZH).
- SUMMARY.md navigation updated for both languages.

## Security Notes

- **EL-REQ-001/002** — Discovery events: only allowlisted fields stored; `password`, `command`, `env`, `image` are permanently excluded from the event schema.
- **EL-REQ-003** — Outcome events verified server-side against instance ownership; client cannot forge `inst_id` or `outcome`.
- **XSS** — Log viewer sanitises all user-supplied and server-returned content before `v-html` injection.
- **WebSocket auth** — Token sent in first message after handshake, not in the URL, to avoid exposure in server access logs and proxy caches.
- `onCreateInst` remains the **only** permitted instance creation path; no new creation routes were added.
